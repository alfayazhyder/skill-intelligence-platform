## 4. Skill Gap Calculation

The skill gap is calculated as:

Required Level - Current Level = Skill Gap

Example:

Data Visualization

Required Level = 70  
Current Level = 45  

Skill Gap = 70 - 45  
Skill Gap = 25

Therefore, Rahul has a 25-point gap in Data Visualization.

## 6. Purpose of This Data

This data will later be used by the backend to:

1. Compare current skills with required skills.
2. Identify skill gaps.
3. Calculate the size of each gap.
4. Help identify suitable learning recommendations.
5. Support the employee dashboard and admin analytics.
