# Mock iGOT Service

This module simulates an external learning-platform integration.

IMPORTANT:
This is demo data and is not official iGOT course data.

## Purpose

The Mock iGOT service provides simulated courses for employees based on their identified skill gaps.

## Functions

- List courses
- Match courses by skill
- Enrol employee
- Return completion status

## Course Fields

- courseId
- title
- description
- skills
- difficulty
- duration
- provider
- enrolled
- completed
